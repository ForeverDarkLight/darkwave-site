# Darkwave — сайт-презентация

Актуальная винтажная версия сайта Darkwave 1.0.0. Статический сайт: не требует npm, сборки или серверной части.

## Что обновлено

- Сохранён фирменный винтажный стиль: тёплые тёмные поверхности, коричневые оттенки и медовые акценты.
- Добавлена отдельная секция **Discord Rich Presence (RPC)**. По актуальным экранам приложения указано, что Darkwave передаёт в настольный Discord название трека, исполнителя и время воспроизведения; функцию можно включить в настройках.
- Заменены старые изображения на актуальные скриншоты Darkwave 1.0.0: главная, поиск, «Моя волна», комнаты, коллекция, скачанное, локальные файлы, профиль, настройки/темы и перенос библиотеки.
- Обновлён пример Discord Rich Presence: теперь показана компактная карточка «Слушает Darkwave» с названием трека, исполнителем и прогрессом воспроизведения.
- Убран декоративный бейдж, который перекрывал переключатель Discord в настройках; блок интеграции стал компактнее.
- Скриншоты интерфейса открываются в увеличенном просмотре по клику или клавишам Enter/Space; закрытие — по Esc или нажатию вне изображения.
- Скриншоты на главной странице и странице комнат открываются крупно по нажатию; закрытие — по Esc или клику вне изображения.
- Кнопка скачивания подключена к публичному endpoint Cloudflare Worker: `https://darkwave-downloads.frol748748.workers.dev/download/latest`.

## Локальный просмотр

Откройте `index.html` в браузере. Все изображения и фирменная иконка находятся в `assets/`.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в корень репозитория сайта. `index.html` должен лежать прямо в корне.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите `Deploy from a branch`.
4. Выберите ветку `main` и папку `/(root)`, затем нажмите **Save**.
5. После публикации проверьте сайт и тестовую загрузку кнопкой «Скачать Darkwave».

## Скачивание и приватный GitHub Release

Сайт не обращается к приватному GitHub Release напрямую. Кнопка ведёт на Cloudflare Worker, который использует секрет `GITHUB_TOKEN` для чтения приватного Release Asset и отдаёт посетителю установщик. Сам GitHub-репозиторий остаётся приватным.

Текущий адрес кнопки:

`https://darkwave-downloads.frol748748.workers.dev/download/latest`

При публикации следующей версии достаточно создать новый GitHub Release с установщиком и пометить его как Latest. URL сайта менять не потребуется.

**Не добавляйте GitHub token, приватный PEM-ключ или другие секреты в файлы сайта.**

## Структура

- `index.html` — разметка, стили, интерактивная галерея, увеличенный просмотр скриншотов и ссылки.
- `assets/` — скриншоты Darkwave 1.0.0, фирменная иконка и favicon.
- `.nojekyll` — отключает обработку GitHub Pages через Jekyll.

Пути к изображениям относительные (`./assets/...`), поэтому сайт подходит для GitHub Pages и размещения в подпапке репозитория.
